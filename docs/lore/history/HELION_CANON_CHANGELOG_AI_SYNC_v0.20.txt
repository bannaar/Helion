SECTION 1 — DIRECT NAME / TERMINOLOGY CHANGES
======================================================================

1. HELION CONCORDAT -> INTER-GALACTIC GOVERNANCE (IGG)

OLD:
- Helion Concordat
- Concordat, when referring to the umbrella institution
- Concordat gameplay, when referring to the institution as a whole
- Concordat banner / Concordat administration, where the umbrella body is meant

NEW:
- Inter-Galactic Governance
- IGG

IMPORTANT:
- IGG is NOT a galactic government despite the name.
- IGG is an independent treaty authority and interstellar service framework.
- IGG is not a sixth sovereign faction.
- IGG does not own national territory.
- IGG is the umbrella framework for three coequal arms:
  * INSA — Interstellar Navigation & Security Authority
  * Gatewatch
  * Galactic Defense Force (GDF)
- The Crossroads Charter name is RETAINED.
- The old principle "No flag owns the road between stars." is RETAINED.
- The operational shorthand "INSA knows. Gatewatch understands. The GDF acts."
  is RETAINED.
- Historical references to the old development term may remain only when a
  document is explicitly describing superseded project history.

2. GALNET -> UNINET

OLD:
- GalNet
- GalNet news
- GalNet reports
- GalNet economy hooks
- GalNet stories
- GalNet chat/news terminology when meant as current canon

NEW:
- UniNet
- UniNet news
- UniNet reports
- UniNet economy hooks
- UniNet stories

RULE:
Current user-facing lore, documentation, UI text, mission text, and maintained
code comments should use UniNet.

Compatibility-sensitive persisted identifiers, database fields, protocol keys,
or old migration records must not be blindly renamed. Preserve or migrate them
explicitly.

3. CREDITS -> GALACTIC STANDARD CREDIT (GSC)

OLD USER-FACING TERM:
- credits
- Credits
- generic "credit" currency wording

NEW CANONICAL TERM:
- Galactic Standard Credit
- GSC
- GSC balance
- GSC reward
- GSC price

RULE:
Use GSC in current lore, UI text, documentation, mission text, economy text,
and generated narrative.

Internal legacy identifiers such as:
- credits
- credit_balance
- persisted credits fields
may remain temporarily for compatibility. Rename technical identifiers only
through an explicit versioned migration.

The economic categories remain:
- Faucet: GSC created by the simulation.
- Sink: GSC removed from circulation.
- Transfer: existing GSC moved between participants.

4. CONCORDIA -> CROWNSPIRE

OLD:
- Concordia, as the Helion Commonwealth capital

NEW:
- Crownspire

RULE:
Crownspire is the current canonical capital of the Helion Commonwealth.

Do not change unrelated uses of the word "concord" or "Concordia" if they are
clearly historical/non-HELION data, but current HELION capital references must
say Crownspire.

5. TITAN FORGE -> IRONSTAR FORGE

OLD:
- Titan Forge
- Titan visual family, where it refers to that corporation/manufacturer identity

NEW:
- Ironstar Forge
- Ironstar visual/manufacturer identity

RULE:
Preserve the previously approved heavy military-industrial design language:
- heavy
- armored
- powerful
- dense hulls
- visible structural ribs
- externally serviceable systems
- rugged military/industrial engineering

The visual identity survives; only the canonical corporate/manufacturer name
changes.

6. NEW EDEN -> VERDANCE

OLD:
- New Eden, as the named lost agricultural colony

NEW:
- Verdance

CURRENT LORE:
Verdance is a presumed-lost agricultural world with no obvious signs of
catastrophe and no active civilization detected.

7. NULLSEC / NULL SECURITY AS A REGION NAME -> ZERO SPACE

OLD OR DEPRECATED REGION WORDING:
- nullsec
- null space
- Null Space
- Null Security when used as the proper name of the frontier zone

NEW CANONICAL REGION:
- Zero Space
- 0.0
- Zero-security Known Space frontier

IMPORTANT:
- Zero Space is ordinary Known Space with a 0.0 security rating.
- The Null is a completely separate cosmic/existential mystery.
- Never use "The Null" as a synonym for Zero Space.
- If a technical security enum needs a category, use Zero/0.0 semantics rather
  than making "Null" the lore name of the region.

NOTE:
Some draftcomp6 text still contains descriptive "Null Security" wording.
Treat that as stale cleanup debt. The active goal defines the canonical
classification as High / Low / Zero and the canonical region as Zero Space.

8. UNKNOWN SPACE -> RIFTSPACE, BUT ONLY IN A SPECIFIC SCOPE

THIS IS NOT A GLOBAL RENAME.

OLD BROAD USAGE:
- Unknown Space was sometimes used as a catch-all name for persistent systems
  reached through unstable Rifts.

NEW OPERATIONAL TERM:
- Riftspace = persistent systems/regions reached through unstable Rifts.

RETAIN:
- Unknown Space may still be used as the broader scientific/mystery domain.
- Deep Unknown Space remains a broader/deeper category.
- Riftspace is outside the 200-system Known Space count.

DO NOT blindly replace every occurrence of "Unknown Space" with "Riftspace."

9. ADAPTIVE TECHNOLOGY -> ADAPTIVE SYSTEMS ARCHITECTURE (ASA)

OLD / INFORMAL:
- Adaptive Technology
- generic hybrid alien-tech tier wording

NEW FORMAL NAME:
- Adaptive Systems Architecture (ASA)

COMMON NAME STILL ALLOWED:
- Adaptive Technology

DESIGN RULE:
ASA is not a simple numbered "better tech tier." It emphasizes configurable
capabilities, unusual operating modes, hybrid engineering, scarce inputs,
research burden, maintenance complexity, and specialized use.

10. LEGACY STARTER HULL NAME -> RETIRED, FINAL REPLACEMENT NOT YET LOCKED

OLD:
- Sidewinder

CURRENT STATUS:
- The external-setting starter hull name is NOT current HELION canon.
- Current draft tables use "Starter Shuttle" as a neutral placeholder/reference.
- No final one-to-one canonical replacement name has been formally locked in
  this synchronization package.

RULE FOR OTHER AIs:
- Remove Sidewinder from current lore-facing text.
- Do NOT invent a final replacement hull name.
- Preserve compatibility-sensitive old IDs in code/save migrations until a
  deliberate migration is approved.
- Use "starter shuttle" generically where necessary until a final name is
  explicitly selected.

11. EXTERNAL-SETTING HEAVY/CAPITAL CLASS NAMES -> HELION-NATIVE ROLE FAMILIES

Do not preserve external-setting class vocabulary as HELION canon.

APPROVED FUTURE COMBAT / STRATEGIC ROLE FAMILIES:

- Aerie
- Grand Aerie
- Dominion

APPROVED FUTURE INDUSTRIAL / LOGISTICS ROLE FAMILIES:

IMPORTANT:
These are approved future role-family names, not proof that those ships are

SECTION 8 — SPACE DATA MODEL CHANGES
======================================================================

These concepts must remain independent rather than being collapsed into one
"system type":

1. SPACE DOMAIN
   - Known
   - Rift
   - Deep Unknown or equivalent

2. SECURITY CLASSIFICATION
   - High
   - Low
   - Zero
   - Unrated where appropriate

3. SOVEREIGNTY
   - major NPC faction
   - unclaimed
   - future player organization
   - eligible non-national NPC where explicitly supported
   - none

4. STRUCTURE OWNERSHIP
   - ownership of a station/installation/structure
   - does NOT automatically imply sovereignty over the star system

5. DISCOVERY / KNOWLEDGE STATE
   - what a specific viewer actually knows about an object/system

Riftspace has no ordinary system-level sovereignty.
Owning a structure in Riftspace does not mean owning the system.

  ->
