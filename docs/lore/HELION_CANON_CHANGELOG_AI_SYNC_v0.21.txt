  meaning. Unknown Space remains a broader scientific/mystery term; no global rename.
- Zero Space is the proper 0.0 frontier name; obsolete Null Security region prose
  should use Zero Space / Zero security. The Null is a separate cosmic mystery.
- Adaptive Systems Architecture (ASA) is the formal advanced/hybrid discipline.
  Adaptive Technology remains allowed colloquially; it is not a superior-number tier.
- Sidewinder is a superseded external-setting starter name, not immutable HELION
  lore. Use generic starter shuttle pending approval of a final native name.
  Preserve SIDEWINDER/sidewinder technical identity until an approved migration.
- Veyra and AsterTech are unresolved review items, not automatic replacements.
  Aster Dynamics remains the established manufacturer; the AsterTech marque question
  remains open. Do not invent Veyra lore or replace Khepri/Vael with it.
- Original heavy-family direction remains: Breaker, Aerie, Grand Aerie, Dominion;
  Fleet Tender, Foundry Tender, Bulk Liner, Farline Liner. These are future roles,
  not proof of playable ships or a one-to-one mapping from external settings.

AUTHORITATIVE ARCHITECTURE AND ENVIRONMENTS
------------------------------------------
Authoritative path: native C++ persistent server + native SDL2/OpenGL C++ client.
src/ browser runtime: legacy/reference, not a peer production runtime, second
authoritative universe or second persistent backend.
Server owns authoritative position/velocity, docking/launching, ships, implemented
equipment, inventory/cargo, economy, missions, security, implemented combat,
progression, persistence, environment identity, roles and administration.
Clients request actions; they do not grant themselves state.

PRODUCTION: canonical persistent universe, can run with zero players.
PRIVATE TEST: isolated, noncanonical, resettable developer/invited-tester service.
DEVELOPMENT: local/disposable/diagnostic.
DEV_ADMIN TEST privileges confer no Production gameplay mutation authority.
INVITED_TESTER does not automatically gain developer administration.
Environment and role claims from clients are non-authoritative.

M7 established local service lifecycle, fail-closed startup, health/readiness,
structured operations logs, lightweight process metrics, maintenance preparation,
bounded drain, durable shutdown checkpoints, verified Production backups,
non-destructive restore verification/planning and Linux/systemd examples.
TEST snapshots remain separate from Production backups. No destructive Production
restore or remote operations API is claimed; see docs/production-operations.md.

OPTIONAL COMPANIONS
-------------------
Future clients may include HELION Commander, HELION Terminal, HELION Flight Deck,
mobile/tablet interfaces, cockpit devices, Vita-style cockpit interfaces, Linux
cyberdecks and other cockpit hardware. No companion is required to play.
Companions consume permission-filtered data and submit permitted requests through
existing server boundaries. They host no canonical simulation/backend, inherit no
Production administrator authority and receive no hidden truth merely because the
UI could conceal it. Current profile.read credentials are a narrow foundation,
not implementation of every future device or general gameplay automation.
